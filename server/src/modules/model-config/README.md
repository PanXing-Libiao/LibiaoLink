# 模型服务配置

系统管理员可在头像菜单进入模型管理，保存多套 OpenAI 兼容服务，通过服务的 GET /models 获取模型列表，并选择一个全系统使用的对话模型。管理接口统一经过登录、CSRF 和系统管理员权限校验。

- 配置：服务名称、接口基址、加密后的 API Key；修改时密钥留空表示保留，地址变化必须重新输入或明确清除密钥。
- 密钥：使用 MODEL_CONFIG_ENCRYPTION_KEY 对每个服务的 Key 做 AES-256-GCM 加密；API 和审计不返回、记录 Key。密钥保护配置缺失时，不能保存需要 Key 的服务。
- 当前模型：数据库单例选择同时供 Excel 节点语义匹配和文本翻译使用。未启用模型时沿用原有环境配置；启用后不继续使用旧翻译备用模型。
- 导入：配置不可用、模型不确定或网关失败时，节点进入人工确认，不自动匹配或补库。
- 模型列表只反映服务返回的 ID，不保证模型支持对话；管理员应选择可用于 chat/completions 的模型。
- 删除当前服务会清除当前选择，系统回到原有环境配置。已有翻译缓存不因模型切换自动重翻。
- 发布前准备独立的 32 字节 base64 密钥并通过受控 Secret 注入；密钥不可随意轮换，轮换后需重新设置已保存的服务 Key。
