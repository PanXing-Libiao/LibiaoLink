# A08 大阶段完成通知（项目群播报）

- 状态：2026-10-19 落地（Push 372）；2026-10-19 Push 373 当前停用（`enabled: false`），规则定义与 `A08_GROUP` 模板保留；2026-10-26 消息标题增加 emoji；规则码 `A08`。
- 触发：outbox 主题 `stage.advanced`（阶段推进事务内写入；阶段已完成、下一阶段已激活）。
- 收件人：项目群（`project.group`，寻址键 = 项目 id；绑定 / 激活由 `notify.group` 消费端统一判定）。
- 渠道：企微群机器人（`wecom_group`，`notify.group` 消费）。

## 文案（逐字）

| 项 | 内容 |
|---|---|
| 标题 | 🏁 大阶段完成通知 |
| 正文 | 项目：**{项目}**<br>{推进人}已完成大阶段「**{完成阶段}**」，当前项目阶段：**{下一阶段}**。 |

字段口径：

| 变量 | 取值 |
|---|---|
| `{项目}` | `project_code·project_name`（项目编号 · 项目名称） |
| `{推进人}` | 阶段推进操作账号的显示名；查不到时 = 「未知用户」 |
| `{完成阶段}` | `project_stages.stage_key` → 九阶段字典名称（售前规划 / 设计开发 / … / 验收） |
| `{下一阶段}` | 事件载荷 `nextStageKey` → 阶段名称；末阶段 = 「项目流程已完成」 |

## 金标与边界

- 当前停用，阶段推进不产生 A08 消息；恢复启用后，阶段推进事件命中 → 每个项目群一条；标题加粗、正文与标题之间空行（群投递层统一组装）。
- 条件命中后先产出 `notify.group`；群未绑定 / 未激活时由消费端转 dead、降级项目经理站内信并发送一次专用告警。条件未命中则不产消息、不告警。
- 同一阶段同一推进版本只播报一次；幂等键 = `A08:{stageId}:v{stageVersion}`。
- 阶段事件不套用任务完成态判断；`stage.advanced` 是独立事件主体（`kind = stage`）。
- 回滚（`stage.rolled_back`）不触发 A08。
