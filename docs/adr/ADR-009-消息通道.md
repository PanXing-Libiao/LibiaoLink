## 背景

用户都在企业微信；提醒类消息（到期 / 启动 / 超时 / 成果文件 / 审批）与群播报（喜报、阶段达成、日报汇总）是自动化规则的出口。外发消息必须「至少一次 + 幂等 + 渠道限速 + 失败可降级」。

## 决策

- **一期主渠道**：企微自建应用消息（个人提醒）+ 群机器人 Webhook（群播报）。**【修订 2026-10-14 · lan 代行定案，请 wmj 复核：已被 ADR-033 承接 —— 企微外发（群播报 + 单聊提醒）改走智能机器人（aibot）；应用消息保留为未启用备用通道（回退 = 4 条内置规则渠道值回切 `wecom_app`）】**
- **兜底通道**：站内信（全量记录与审计，轮询模式）。
- **适配位（不实现）**：邮件、短信、钉钉、飞书——统一走 ChannelAdapter 适配层；邮件随二期周报 / 风险推送启用（优先评估公司邮箱 SMTP 中继）。
- 投递语义：Outbox（ADR-005）至少一次投递 + 幂等消费 + 渠道限速（群机器人 20 条 / 分钟，待实测）+ 失败降级（企微失败 → 站内信保底）+ 死信 / 连续失败告警。**【修订 2026-10-14：限速口径随 aibot 形态改按会话双窗口（30 条 / 分钟 + 1000 条 / 小时 · 已实测）；至少一次 / 幂等 / 降级 / 死信告警语义不变】**
- 配套管理：项目与群绑定维护、消息模板（文案以系统功能书为准）、发送记录查询、管理员重发。

## 备选与不采用原因

- 钉钉 / 飞书：其他部门未来可能使用，不实现、仅留适配位。
- 邮件一期不做：涉及域名、退信与运维成本，随二期周报启用。
- 短信：成本与合规，一期不做，保留接口。

## 影响与后果

- 企微配置（应用创建、可信域名、IP 白名单、群机器人）依赖企业管理员配合，是外部依赖项，需尽早启动（企微打通 PoC）。
- 消息内容受权限脱敏约束：消息中的字段必须与权限出口同口径（PoC-6）。

## 切换触发条件

其他部门使用不同 IM（钉钉 / 飞书等）时，启用 ChannelAdapter 适配层并新增通道实现。
