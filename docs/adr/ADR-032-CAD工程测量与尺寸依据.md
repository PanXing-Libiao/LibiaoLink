# ADR-032 CAD 工程测量与尺寸依据（提案撤回）

2026-10-21：旧提案及 CAD-0～CAD-5 任务由 [ADR-035](ADR-035-CAD接入独立能力工程.md) 和 [CAD 平台接入基线与迁移任务](../CAD平台接入基线与迁移任务.md) 替代，不再继续实施。

CAD 接入以独立工程的实际能力矩阵为准，不在 LibiaoLink 重建 importId/featureId、几何查询、工程测量或尺寸依据服务。旧提案未落库的字段与接口不构成公开契约。

旧网格测量实现随旧查看器删除。当前不交付工程测量、PMI、公差推定或加工/验收尺寸依据；如后续需要，按独立工程能力与明确业务依据另行立项。旧全文可从 Git 历史查看。
