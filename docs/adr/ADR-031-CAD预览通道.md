# ADR-031 CAD 预览通道（已替代，旧实现撤下）

2026-10-21：本 ADR 由 [ADR-035](ADR-035-CAD接入独立能力工程.md) 替代。PR #323 的旧浏览器解析器、OCCT WASM、专用依赖与 CAD 原文件图片直签在本轮删除；旧全文及原有缺陷更正保存在 Git 历史。

原 STEP/IGES/STL/3MF/OBJ/glTF 后缀白名单、二维 CAD 的 SVG/PDF 映射、旧 PoC 性能及工程测量声明均不作为当前能力依据。CAD 不再由平台另建解析或测量规则。

当前平台 CAD 暂不可预览，保留有权限的原文件下载。下一步按独立工程 UCD/ViewerSession 接入版本、任务、受控模型资源和完整性提示，见 [接入任务](../CAD平台接入基线与迁移任务.md)。Office、图片和下载继续使用各自既有通道。
