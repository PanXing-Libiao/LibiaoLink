# ADR-007 在线预览：自建转换管道（只读、系统内直接查看）

## 背景

业务确认三条硬约束：① 预览在系统内直接查看，不经过第三方软件；② **不支持在线编辑**；③ 不允许上传第三方云。预览体验对标 ONLYOFFICE 的「查看」能力（不是编辑）。

## 决策

- **自建转换管道**：converter 容器内 LibreOffice headless 转换（Office → PDF）；xlsx 走前端结构化渲染兜底（多 Sheet / 列宽 / 基础格式，复杂图表以 PDF 补充）；PDF / 图片直接渲染。**【修订 2026-10-08 · Push 196（lan 代记，请 wmj 复核）：本决策之 Office / 文本族部分（LibreOffice → PDF 转换与 xlsx 结构化兜底）已被 ADR-030 取代 —— 改由自托管 ONLYOFFICE 只读查看器承接；PDF / 图片直出照旧】**
- 预览**只读**，明确不做在线编辑；ONLYOFFICE Docs / Collabora Online / WPS 365 均不采用（费用调研仅存档，不构成实施方案）。**【修订 2026-10-08 · Push 196：ONLYOFFICE 一项已被 ADR-030 取代 —— 以自托管只读查看器形态采用（系统仍不做在线编辑）；Collabora Online / WPS 365 仍不采用】**
- 沙箱要求（不可省）：无外网、非 root、只读根文件系统、CPU / 内存 / 时间上限、超时杀进程；不触网、不访问数据库与内网。
- 产物与缓存：转换产物键 = 内容哈希 + `pipelineVersion` + `target`（**三元组**，对象键 `previews/{contentHash}/{pipelineVersion}/{target}`）；`target` 必须在键内 —— 同一内容可有多种产物（如 PDF 与 xlsx 结构化数据）；定档文件预生成，其余按需懒生成，同一文件同一三元组只转一次。
- 渲染通道（`target`，三值）：`pdf` = PDF 查看器通道（Office 转出、PDF 源、二维 CAD 若产物为 PDF）；`image` = 图片通道（图片直出、Office 图片型兜底、二维 CAD 若产物为 SVG —— SVG 属 `image/*`，浏览器直接渲染）；`structured` = xlsx 结构化渲染（一期未启用时 xlsx 走 `pdf`）。不新开 `svg` 值：枚举按渲染通道而非文件格式定义；CAD 产物格式与通道归属在 M4-06 PoC 报告写明（条件性交付）。
- `pipelineVersion` = 转换管线版本（转换器实现 + 影响产物的参数 / 模板 / 字体 / 兜底策略等配置的版本标识），服务端配置下发（如 `PREVIEW_PIPELINE_VERSION`）；客户端不解析，仅作缓存失效 / 排障标识；参数变更 = 版本递增 → 旧产物自然失效（键含版本，不原地覆盖）。
- 安全：预览访问走鉴权（短时签名 URL）+ 审计；不允许 MinIO 匿名读取；预览计入「查看 / 下载」审计。
- 降级：转换失败不影响下载；预览页提示「暂不支持在线预览，请下载查看」并记录失败原因。
- 字体：容器必须安装中文字体（含常用宋体 / 黑体映射），否则 PDF 中文乱码——纳入镜像构建门禁。

## 备选与不采用原因

- KKFileView（Apache-2.0）：开箱可用且内置部分 CAD 支持，但引入额外 Java 服务；仅作为 CAD / 三维覆盖不足时的 PoC 候选。
- ONLYOFFICE Docs（AGPLv3 / 商业）：查看体验最好但定位含在线编辑，与「不支持在线编辑」口径不符，不采用。**【已被 ADR-030 取代（2026-09-30 起）：经业务 / 法务确认以自托管只读查看器形态采用（AGPL 社区版；系统不做在线编辑）】**
- Collabora Online：同上；并发与资源占用需 PoC，不采用。
- WPS 365 / 金山中台：商业采购 + 第三方组件，与「不经过第三方软件」约束冲突，不采用。

## 影响与后果

- 预览质量是产品风险项：Excel 分页、字体、复杂版式需在阶段 0 用真实样本验证（文件管道 PoC）。
- converter 是安全高风险面：恶意文件解析全部在沙箱内完成，不触网、不触库。
- 一期预览仅只读：文件内容修改一律走「下载 → 本地编辑 → 上传新版本 / 变更申请」流程。

## 切换触发条件

CAD 覆盖需求扩大且 KKFileView 类方案 PoC 优于自建（Preview 能力或其费用 / 运维成本显著更优）时，重新评估。
