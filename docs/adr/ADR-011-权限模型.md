# ADR-011 权限：自研策略层（RBAC + 数据 / 记录 / 字段 / 操作五层）

- 状态：草案（Proposed）｜评审：lan、px｜随 PR 合并 main 后转「已采纳（Accepted）」
- 日期：2026-09-18｜决策人：wmj（技术负责人）
- 依据：技术设计v0.1-选型分析.md §0.1、§4.12、§5（#12）；技术设计v0.2-架构与数据模型.md（权限模型篇）

## 背景

需求含「指定内容不可见」：字段级可见性与脱敏、导出 / 下载 / 外链受控、全程留痕。300 人规模角色少于 30 个、字段策略少于 200 条，策略量小。

## 决策

自研策略层（PDP + 策略表），五层模型：

- 功能权限：模块 / 操作（查看、编辑、删除、导出、下载、审批）；
- 数据范围：全部 / 本部门 / 我参与的 / 我负责的 / 自定义项目集；
- 记录权限：项目成员制（非成员不可见，统一 404 语义）；
- 字段权限：可见 / 只读 / 隐藏脱敏——**无权限字段不返回**，不做前端打码；
- 时效：临时授权到期自动收回；外链限时 / 限权 / 水印。

性能：策略全量加载内存 + 版本号失效，不引入复杂缓存层。

**不变量（写进仓库规则与 CI）**：

1. 权限判定只在服务端执行，前端隐藏仅是体验优化；
2. 导出、搜索投影、消息内容、统计接口与页面走同一策略出口；
3. 资源不存在与无权访问统一返回 404（防 IDOR 探测）；
4. 导出 / 下载 / 预览 / 外链生成全部审计，越权尝试单独留痕并告警；**【修订 2026-10-23：预览在实际送达就绪内容时恢复写审计（未就绪 / 失败 / 404 不写）；新增 `visit` 记录项目详情访问 / 登录成功；推进 / 回退值保留，仅操作记录动作筛选隐藏；导出 / 下载 / 外链生成审计与越权留痕不变】**
5. 权限矩阵为 CI 门禁：每条路由至少一组允许 + 一组拒绝用例。

**范围例外（2026-09-17 已确认）**：一期流程节点体系不做权限控制——节点操作可见即可执行（不区分角色），但完成 / 回退 / 增删全程留痕；模型为节点操作预留策略位，二期随审批场景启用。

## 备选与不采用原因

Casbin 等策略引擎：DSL 学习与调试成本高，与本项目的「数据范围 / 字段策略」模型对齐成本高，省下的代码量有限。

## 影响与后果

- 权限是产品正确性的一部分：任何新接口必须同时提交权限用例（Definition of Done）。
- 干系人隐私字段（联系方式等）走字段级权限是硬要求。
- 权限矩阵与脱敏验证是阶段 0 必过 PoC 之一（PoC-6）。

## 切换触发条件

策略规模爆炸（角色超过 100 个，或出现策略 DSL 需求）时，评估第三方策略引擎。
