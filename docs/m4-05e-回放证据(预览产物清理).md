## 未覆盖 / 风险登记

- **回收站到期清理（worker 定时档）走的是同一个 `purgeRecycled`**：真机回放按「管理员手动彻底删除」两条覆盖（A / B），定时档路径由单测 `test/file-service.test.ts` 的 sweep 用例覆盖（`RECYCLE_SWEEP_INTERVAL_MS` = 24 小时，等真实定时档不现实）。
- **反查未加索引**：`findVersionByContentHash` 按 `file_versions.content_hash` 扫描（无索引）。彻底删除是低频批处理，暂可接受；量大后按需补一条只追加索引迁移（登记为后续项）。
- **跨项目同内容**：本脚本的 A / B 在同一项目内；跨项目复用同一三元组是同一逻辑（反查不带项目条件），未单独覆盖。
- **压测未做**：并发 2~4、200MB 级长跑、转换成功率 ≥95%（PoC-1 真实样本集）属 M4-05 压测 / M8 容量验证。
