## 二、共享契约变更

### 2.1 `shared/src/modules/automation.ts`

1. `AUTOMATION_RULE_CODES` 增 `A08`；保留 R01 ~ R07、A01、A02、A14；A03 不恢复。管理列表一期仅返回可视化管理的规则，R01 不入管理列表。
2. 新增 `NotifyExternalChannel`：`wecom_app` / `wecom_aibot` / `wecom_group` / `email`。该枚举用于发送尝试记录，**不含 `inbox`**。
3. 新增运行跳过原因 `AutomationRunSkipReason`：`disabled` / `subject_mismatch` / `window_mismatch` / `not_matched` / `recipient_missing` / `template_missing` / `duplicate` / `event_too_old`。
4. 新增 `AutomationRuleView`：完整规则 + `id` / `code` / `builtIn` / `editableFields` / `lastRunAt` / `nextRunAt` / `scheduleJobStatus`。无可关联调度 job 或尚未运行时，对应字段为 `null`。
5. 新增 `AutomationRuleListResponse`：最多 100 条，按 `code` 升序；一期固定为内置规则，停用规则仍返回。
6. 新增 `AutomationRulePatchBody`：
   - `version` 必填并作为乐观锁；
   - `enabled` 与 `actions` 至少提交一项；`actions` 为 1 ~ 10 项并保持原数组顺序；
   - 仅允许变化 `enabled`、`actions.channel`、`actions.recipient`；
   - 顶层对象使用严格模式，夹带 `code`、模板、触发、条件或其它只读字段直接拒绝；
   - 版本冲突返回 `409 VERSION_CONFLICT`。
7. 新增只读试运行契约：
   - `AutomationRuleTestBody`：`businessDate` 可选（缺省今天，Asia/Shanghai），`entityId` 可选；事件型规则实际调用必须提供 `entityId`；
   - `AutomationRuleTestResponse`：`businessDate`、评估 / 命中 / 跳过计数、`truncated`、`messages[]`、`skipped[]`；
   - 调度型最多评估 100 个主体，超出以 `truncated = true` 表达；
   - 试运行不写 `automation_runs`、outbox 或审计。
8. 新增 `AutomationConditionEvaluation` 与 `AutomationMessageSnapshot`：前者保存 field / op / expected / actual / passed，后者保存收件人、渠道、模板、幂等键、标题与正文快照。
9. 新增 `AutomationRun` / `AutomationRunListQuery` / `AutomationRunListResponse`：
   - 运行记录按规则 × 实体 × 窗口留痕，保存 `dedupeKey`、状态、跳过原因、条件 / 动作 / 消息快照与已掩码错误；
   - `ruleId` 在规则删除后可为 `null`，`ruleCode` 快照保留；
   - 事件型 `topic` 为枚举，调度型为 `null`；
   - 列表按 `createdAt desc, id desc`，支持规则 / 状态 / 来源 / 主题 / 实体 / 时间区间 / 分页筛选。

### 2.2 `shared/src/modules/notifications.ts`

1. 新增 `NotifyDeliveryTopic`：`notify.message` / `notify.group`。
2. 消息级状态为 `pending` / `sent` / `failed` / `deferred` / `dead`；尝试级状态为 `sent` / `failed` / `deferred` / `dead`，`pending` 不落尝试表。
3. 新增消息级 `NotifyDeliveryMessage`：
   - 保存来源 dedupeKey、主题、渠道、收件人展示值 / 掩码、标题正文、模板、规则码、关联对象、重发来源、最新状态、尝试次数、错误与时间；
   - 群播报的 `recipientId = null`；`recipientLabel` 只允许展示值或掩码，不得返回 Secret；
   - 消息归档独立于 outbox 清理，列表按 `createdAt desc, id desc`。
4. 新增尝试级 `NotifyDeliveryAttempt`：`messageId`、外部渠道、`targetMasked`、状态、尝试序号、已掩码错误与受理时间；不返回完整 userid / chatid / 原始载荷。
5. 新增 `NotifyDeliveryListQuery`、`NotifyDeliveryListResponse`、`NotifyDeliveryDetail`：列表支持渠道 / 最新状态 / 规则 / 收件人 / 时间区间 / 关键字 / 分页；详情附加全部尝试。
6. 新增 `NotifyDeliveryResendBody`：严格空对象。正文、收件人、渠道等任何额外字段均拒绝；幂等键走请求头 `Idempotency-Key`。
7. 新增 `NotifyDeliveryResendResponse`：返回新建的消息归档，`lastState = pending`，原消息、原尝试和原状态均不改写。

### 2.3 生成物可空性

本切片新增的可空引用字段统一使用 `z.union([Schema, z.null()])`，生成 OpenAPI `anyOf: [ref, null]`，避免 `allOf` 与基 `$ref` 组合后在 JSON Schema 语义下把 `null` 排除。覆盖规则运行时刻 / job 状态、运行记录规则 id / 主题 / 跳过原因、发送记录收件人 / 发送时刻等字段。

## 三、OpenAPI 操作

| 方法 | 路径 | 权限 | 语义 |
|---|---|---|---|
| GET | `/api/v1/automation/rules` | `automation.view` | 规则管理列表，含停用规则与调度 job 状态 |
| GET | `/api/v1/automation/rules/{code}` | `automation.view` | 规则详情 |
| PATCH | `/api/v1/automation/rules/{code}` | `automation.manage` | 乐观锁保存启停 / 动作渠道 / 收件人 |
| POST | `/api/v1/automation/rules/{code}/test` | `automation.manage` | 只读试运行，返回命中 / 跳过 / 条件明细 |
| GET | `/api/v1/automation/runs` | `automation.view` | 运行记录列表 |
| GET | `/api/v1/automation/runs/{id}` | `automation.view` | 运行记录详情 |
| GET | `/api/v1/notifications/deliveries` | `notify.record.view` | 消息级发送记录列表 |
| GET | `/api/v1/notifications/deliveries/{id}` | `notify.record.view` | 消息归档 + 全部尝试明细 |
| POST | `/api/v1/notifications/deliveries/{id}/resend` | `notify.resend` | 幂等重发失败 / 死信外部消息 |

约束：

- `/notifications/deliveries` 静态段必须先于 `/notifications/{id}` 声明，避免被参数路由截获。
- 规则保存冲突或不可修改返回 409；事件型试运行缺 `entityId` 返回 400；无权与不存在统一按 404 处理，不泄漏资源存在性。
- 重发仅允许 `wecom_app` / `wecom_aibot` / `wecom_group`，且消息最新状态必须为 `failed` 或 `dead`；`inbox`、`email`、`pending` / `deferred` / `sent` 均不允许。
- 重发缺少或非法 `Idempotency-Key` 返回 400 `VALIDATION_FAILED`；同一 key 重试返回同一结果。

## 四、权限与审计

`PERMISSION_KEYS` 由 32 项增至 **36** 项，仅 admin 拥有：

| 权限键 | 用途 |
|---|---|
| `automation.view` | 查看规则与运行记录 |
| `automation.manage` | 启停 / 配置 / 试运行 |
| `notify.record.view` | 查看发送记录与尝试明细 |
| `notify.resend` | 重发失败 / 死信消息 |

审计对象增 `automation_rule` / `notify_delivery`：

- 规则变更：对象 id = 规则 id；metadata 记录 code、beforeVersion、afterVersion，changes 记录字段级 diff；
- 管理员重发：`action = update`，metadata 记录 `operation = resend`、来源消息 id 与新 outbox dedupeKey；
- 系统自动重试不写审计；试运行与普通读面不写审计。

`database/seeds/role-permissions.mjs` 同步为 admin 全量 36 键，其余角色不增。
