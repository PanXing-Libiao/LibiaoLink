# DWG 原生接入 UCD：本机实现与后续门禁

依据当前任务选择 ACadSharp。输入为原 DWG，UCD 为共同基础；不经过 DXF，不新建另一套查看器。正式原图、转换产物、逐句柄账本和图纸截图仅保留在忽略目录。用户随后授权整理换机交接并推送 `wmj`；本次提交为开发检查点，不部署。准确续接状态见 [DWG_HANDOFF.md](../../../server/cad-engine/DWG_HANDOFF.md)。

## 当前实现

| 责任层 | 实现 / 调用方 | 规则与验证 |
|---|---|---|
| 原生读取（wmj / CAD） | `server/cad-engine/dwg-reader` | 固定 ACadSharp 3.8.30 源码与子模块；BS 的 INTERSECTIONCOLOR 与 CMC 的 INTERFERECOLOR 分离。严格读取，保留原值与非致命警告。原生 DWG 读写回归验证不同字段不再互相覆盖。 |
| UCD 映射（wmj / CAD） | `core/unified/dwg_adapter.py`、`core/dwg_convert.py` | 原格式 / 保存版本 / 完整摘要 / 原句柄独立保留；块定义与实例不提前展开。保留源账本、原生字段及损失；未知对象为 unsupported 或明确缺失。 |
| 公共 UCD | `core/unified/validation.py`、`canonical.py` | 大表成员与引用校验建立一次索引；标准 JSON 编码器流式处理大清单，保持既有序列化字节和 revision 规则。仍执行完整结构、引用、缓冲及摘要校验。 |
| 公共查看器（wmj CAD 专项；px 协办） | 现有 `drawing-viewer.js`、`drawing-projection.js`；新增 `drawing-instances.js` | 普通场景保留既有投影；大模型保留块图、共享源几何，使用 Flatbush 查询与连续笔画批绘。小型等价回归核对样式继承、实例路径、变换、画序与大数量。正式图已实际进入现有查看器。 |
| 文字呈现 | 社区 ACadSharp.Image 的选定方法 | 选择性复用文字转义、段落与换行方法，保留 MIT 许可和内容摘要；没有整体引入社区应用、栅格后端或 SixLabors 依赖。缺原字体和富文本排版等价性仍为损失。 |
| 本机入口 | `dev/dwg-local.py` | 仅回环地址；加载已校验产物，复用平台 HTML 和同一 mountDrawingViewer。没有生产上传接口，没有源 DWG 下载。 |

本机正式图原生句柄 902,137 个；模型、布局和标注存储图形涉及 430 个可达块。首轮现有查看器实际打开约 147.8 万个展开绘制项。数量是此文件的观察值，不是覆盖率，也不是完整显示证明。

## 尚未开放的主图业务链路

1. **输入与权限**：file / preview 层仍维持原有开关。本地原生适配器不能作为平台已开放 DWG 的证据。后续识别按签名 / 版本，读取当前上传版本的只读原对象，不用扩展名或中间产物替代源身份。
2. **源身份**：主图源资产继续绑定 `fileId + versionId + 原文件 SHA-256`。缓存须包含读取器二进制、源码补丁、适配规则和配套资源摘要；禁止只按文件名或中间几何命中缓存。文档内短外键不截断完整摘要。
3. **配套资源**：后续复用平台权限与上传版本绑定的资源集合。先从原 DWG 的字体、图片、外参等请求声明建立清单；缺原配套明确呈现。不得依据图纸中的任意路径访问本机文件或网络。
4. **任务与沙箱**：沿用现有任务、取消、进程组终止、禁网、只读根目录及缓冲租约。DWG 原生任务独立选择读取器，不进入 DXF 外参转换入口。失败不得输出 complete / 成功空图。
5. **资源门禁**：不沿用外参的 15 秒 / 128 MiB 预算，也不直接修改现有主图政策。正式样本默认 .NET 托管堆提交约 3 GiB，1.5 / 1.75 GiB GC 堆硬上限均失败；现有 Linux 容器 3 GiB 硬限额、禁 swap，worker 另有 2 GiB RSS 采样阈值，当前未验证达标。需要社区读取器内存优化，或另行确认且经过 Linux 实测的主图资源政策。当前不开部署开关。
6. **查看器**：生产入口后续按 UCD drawing 能力装载，不以 DXF 名称决定能力。完整清单和缓冲均需通过既有验证与租约边界；原句柄 / 原文件摘要、损失和字体替代应可查看。对剪裁、逐绘制项格式变体等尚未支持的大图组合应明确失败，不能悄悄丢项。
7. **部署依赖**：新增 .NET 10 运行时与固定 ACadSharp 产物，携带 MIT 许可、源码修改及二进制摘要；仍需 Linux 沙箱验证。独立 CLI 本身不是许可结论。若以后采用 ACadSharp.Image 的其他后端，需单独核对其 SixLabors 依赖条件。

## 必须继续验证

- 正式原图：全图、主结构、尺寸标注、多行中文、填充、引线、代理图形、布局及按原句柄定位，与独立 CAD 原图逐项对照。
- 已出现但未完成的内容：REGION/ACIS 二维边界、多线、构造线、引线箭头、部分代理样式、原字体及富文本；不能全部称作“三维范围之外”。
- 内存与输出：分别记录读取、映射、校验、序列化和浏览器阶段；区分 macOS 压缩后的 RSS、托管堆和 Linux 限额。清单临时文件超过 256 MiB 不发布为成功结果。
- 回归：原生头字段、社区文字换行、UCD 精确序列化、成员归属 / 孤立 / 重复、投影等价、非均匀变换、源句柄拾取、图层开关、布局切换及取消。公共层变更需执行现有 UCD 契约回归；不以测试数量外推任意图纸覆盖率。
