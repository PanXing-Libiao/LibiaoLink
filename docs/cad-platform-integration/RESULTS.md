进度与时间分开表达：转换工作量未知时原生 `<progress>` 不设 value，只显示活动状态和任务阶段；读取几何时按实际收到的字节 / manifest buffer 总字节显示百分比，原长度和 SHA 校验仍执行。模型安装并等待两个动画帧后才报告就绪。排队期间不显示倒计时，按轮询到的 queued 状态扣除排队用时。

估算仅用于等待提示。同文件/版本/引擎最近三次成功打开的有效用时保存在本标签页 sessionStorage，取中位数的 0.8–1.4 倍作为范围，取消和失败不写入。首次使用工程粗估 `T = 8 + 1.1 × 输入 MiB` 秒，范围为 `max(5, 0.7T)` 到 `max(15, 2T)`，剩余值以 5 秒为粒度；超过上界显示“耗时比预计更长，仍在处理中”。此公式不是复杂度预测或 SLA，存储不可用时也可正常查看。

## 使用边界

本轮使用页面明示的测试身份、文件记录和 ObjectStorage，实际守卫/服务/转换/查看器是真实代码。公司 SSO、数据库、真实对象存储、下载整链和正式部署仍需公司测试环境验收；检查页的原文件下载按钮仅验证回调。当前生产 Alpine/768 MiB API 环境需要另配 native runtime、内存和隔离，不能直接开启。尚未推送、合并或部署。

只开放 STEP，外部资源解析与 EASM/DXF 平台入口未加入。每次新窗口当前仍重新转换；P01 本轮未重跑，不据本表宣称大文件提速。独立工程原有外部组 18/19、新增组 20/20、工程夹具 2/2、另一批外部组 19/20 保持分组记录，本轮没有重跑它们，也不把三个集成样本换算为总体支持率。
