## 判定标准

| 判定 | 依据 |
|---|---|
| **删** | 复述界面上已可见的信息 / 同页重复 / 与当前操作无关 |
| **改** | 信息有用但太长 —— 压成一句，或把长解释收进 `title` 悬停 |
| **留** | 无障碍 `*Aria`、输入占位、空态下一步、阻断 / 校验 / 排障信息、业务规则、悬停态提示、图表图例与数据口径 |
