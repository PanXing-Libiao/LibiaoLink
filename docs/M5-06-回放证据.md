### 口径登记

1. **只读字段 / 动作数量变更返回 409**：按已冻结的 S8-4「规则保存冲突或不可修改返回 409」执行。统一错误码表暂无通用 `CONFLICT`，回放沿用 `VERSION_CONFLICT` 作为 409 业务码；消息体明确写「只读 / 不可修改」，前端按 409 + `details` 展示，不自动覆盖。
2. **试运行 `matchedCount` = 命中求值明细数**（`rule × entity × window`，与 `replayRules.matched` 同口径），不是消息条数；一条命中可因多收件人 / 分组合并产出多条消息。
3. **试运行 `recipient` = 展示值**：优先收件人姓名，其次收件人口径（如 `project.group`）；不返回内部 UUID 作为展示值。
4. **`POST /rules/{code}/test` 固定 200**（控制器 `@HttpCode(200)`）；契约声明为 200，避免 Nest 默认 201。
5. **CI 顺序**：1B 回放必须放在 M3-06 / M6 之前。调度型试运行按全库任务主体池取前 100 个；若先跑 10k 任务压测，截断集合会被其它回放数据占满，断言失去意义。
