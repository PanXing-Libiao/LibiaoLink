## 二、状态语义口径（定案后）

| 状态 | 语义 | 响应 | 前端行为 |
|---|---|---|---|
| `ready` | 产物就绪 | 200 + `url` + `expiresAt` + `target` + `pipelineVersion` + `generatedAt` | 内嵌查看器（PDF / 图片） |
| `not_ready` | 尚未生成 | 200 + URL 相关字段全空 | 占位 + 轮询；服务端幂等补投生成任务（按三元组去重），**不引入请求约定** |
| `failed` | 转换失败 | 200 + `reason`（≤ 500 字） | 失败态 + 「暂不支持在线预览，请下载查看」（D2-05） |

- **版本**：查询参数 `versionId` 缺省 = 当前版本；不属于该文件 / 不存在 → 404（A4-06）。
- **缓存键 = 内容哈希 + `pipelineVersion` + `target`**（ADR-007 / v0.2 §5.4 三元组）；`pipelineVersion` = 转换管线版本（转换器实现 + 影响产物的参数 / 模板 / 字体 / 兜底策略，服务端配置下发如 `PREVIEW_PIPELINE_VERSION`；客户端不解析，仅作缓存失效 / 排障）；产物按三元组唯一，转换器或参数变更 → 版本递增 → 缓存整体失效、按需重转。
- **鉴权**：对象存储禁止匿名读取（D2-04）；`url` 一律短时签名（`S3_DOWNLOAD_URL_TTL_SECONDS`，默认 300）。读取面记录级语义随 M4-05 实现（非成员 404）。
- **审计**：`object_type = file`（object id = fileId）+ `action = preview` + `metadata`（versionId / target / pipelineVersion）；**仅「返回 `ready`（下发签名 URL）」的读取写审计** —— `not_ready` 轮询与 `failed` 读取不写（避免轮询噪声）；生成失败记 `preview_artifacts.error`。

## 三、评审定案摘要（wmj · PR #103）

- **三项提请口径**：① `target` 三值够用 —— 按渲染通道定义、**不新开 `svg`**（CAD 当前不占这些通道，后续模型资源按 ADR-035 单独适配；旧 CAD→SVG/PDF 提案撤回）；② `pipelineVersion` + 三元组缓存键按草案表述成立；③ `not_ready` **不引入请求约定**（不采用 `Accept-Preview: generate` —— 懒生成 = GET 的幂等副作用）。
- **两处必须调整（已改）**：① `AUDIT_OBJECT_TYPES` **不加 `preview`**（沿用 `object_type = file` + `action = preview` + metadata，避免「同一 fileId 两种对象类型」的两套检索口径；`change` 保留）；② 补可选查询参数 `versionId`（A4-06）。
- **命名 / 描述（已改）**：`previewedAt` → `generatedAt`（对齐 `preview_artifacts.generated_at`）；`structured` 描述改「一期未启用时 xlsx 走 `pdf` 通道」；`reason` 限长 `max(500)`；`image` 描述补「含矢量 SVG 产物」，CAD 模型资源已改为 ADR-035 独立接入，不占既有 `PreviewTarget` 通道。
- **文档回写（wmj 线 · PR #105 / Push 135）**：ADR-007 决策区、v0.2 §5.4、v0.3 §3.5 的缓存键已统一为三元组，并补 `target` 三值定义与 `pipelineVersion` 语义 —— 本 PR 不重复改 `技术设计*` / `docs/adr/`。
